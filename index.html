⚠️ Perlu Setup Firebase Console

📋 Langkah 1: Enable Google Sign-in

  1. Buka Firebase Console → Sign-in method
  2. Klik provider Google
  3. Toggle Enable ke ON
  4. Support email: kkgpainagreg@gmail.com
  5. Klik Save

📋 Langkah 2: Tambah Authorized Domain

  1. Buka Firebase Console → Settings
  2. Scroll ke Authorized domains
  3. Klik Add domain
  4. Masukkan:
  5. Klik Add

📋 Langkah 3: Update Firestore Rules

  1. Buka Firebase Console → Firestore Rules
  2. Ganti isi rules dengan:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

Klik Publish di kanan atas

📋 Langkah 4: Enable Firestore Database

  1. Buka Firebase Console → Firestore Database
  2. Jika belum ada, klik Create database
  3. Pilih Production mode atau Test mode
  4. Pilih lokasi: asia-southeast2 (Jakarta)

✅ Semua Setup OK!
